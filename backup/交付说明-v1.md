# 飞书 → 雪球发布助手：交付说明

## 已上线地址

https://feishu-xueqiu-assistant.goodsnipe129.chatgpt.site

当前为仅所有者可访问的私有站点，并开启模拟模式。使用同一 ChatGPT 账号登录后，可在 iPhone Safari 打开；通过 Safari 的“共享 → 添加到主屏幕”可作为 PWA 使用。

## 已完成功能

- 飞书 `im.message.receive_v1` 事件接收与 URL 验证。
- Verification Token 校验、来源群 ID 白名单、非文本忽略和请求体大小限制。
- 事件 ID、消息 ID 去重，以及 24 小时相同内容去重。
- 手机号、邮箱、证件号和常见凭证格式脱敏；数据库不保存原始消息。
- 财经关键词筛选、30 分钟同群同主题归并、来源群标记和发布前核对提示。
- iPhone 优先的审核编辑页面、PWA、复制草稿、打开雪球、待确认和已发布状态。
- D1 持久化审核队列与操作日志；雪球账号、Cookie 和未经授权的发帖接口均未使用。

## 验证结果

自动化端到端测试已通过以下 14 项：移动端首页、错误令牌拒绝、飞书 URL 验证、群白名单、非财经筛除、财经草稿、脱敏、事件 ID 去重、内容去重、主题归并、编辑保存、待确认状态、人工发布确认、操作日志。

浏览器以 390 × 844 的 iPhone 尺寸实测通过：生成演示草稿、编辑、复制到剪贴板、切换待确认、标记已发布；控制台无页面错误。

## 当前如何试用

1. 打开上线地址并登录。
2. 在“待审核”空队列点击“生成演示草稿”。
3. 检查来源和脱敏提示，编辑草稿。
4. 点击“复制”或“复制并打开雪球”。
5. 在自己的雪球账户中检查并手工确认发布。
6. 返回助手，在“待确认”中标记为“已发布”。

## 真实飞书接入需要用户提供

1. 飞书企业自建应用，并启用应用机器人能力；把机器人加入目标群。
2. App ID / App Secret：用于在飞书后台识别和管理应用。当前版本不主动调用飞书开放 API，因此这两个值不写入助手，也不需要交给开发者。
3. Event Subscription 的 Verification Token。
4. 允许接入的一个或多个群 `chat_id`，以及对应显示名称。
5. 在飞书后台订阅 `im.message.receive_v1`，申请所需的消息读取权限并发布应用版本。

事件回调地址：

`https://feishu-xueqiu-assistant.goodsnipe129.chatgpt.site/api/feishu/events`

## 上线真实接入前的必要切换

当前站点是私有试用模式，外部的飞书服务器会收到 401，不能调用回调。收到真实 Verification Token 和群 ID 后，需要：

1. 把运行变量 `SIMULATION_MODE` 改为 `false`。
2. 保存真实 `FEISHU_VERIFICATION_TOKEN`（按机密值保存）。
3. 保存 `FEISHU_ALLOWED_CHAT_IDS` 和 `FEISHU_ALLOWED_CHAT_NAMES`。
4. 将站点访问方式改为公开，使飞书可以访问回调；审核页和草稿接口仍由 ChatGPT 登录保护。
5. 在飞书后台完成 URL 验证，并发送一条真实群消息做验收。

不要在公开站点上保留 `SIMULATION_MODE=true`。

## 本地运行

1. 安装 Node.js 22.13 或更高版本。
2. 解压源码，将 `.dev.vars.example` 复制为 `.dev.vars`。
3. 将 `SIMULATION_MODE` 设为 `true`。
4. 运行 `npm install`，再运行 `npm run dev`。
5. 另开终端运行 `npm run test:e2e` 可重复端到端测试。

完整技术说明也包含在源码包的 `README.md` 中。
